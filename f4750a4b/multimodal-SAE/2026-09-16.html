SAE의 특징 분해

Sparse Autoencoder · 소수의 활성 특징을 통한 입력 표현과 복원

  • x, y이미지·텍스트 임베딩의 SAE 입력
  • σ, z̃비선형 활성화 함수 σ를 통한 소수 특징의 활성값 z̃ 생성
  • x̃, ỹ활성값으로 가중한 특징 방향의 합을 통한 입력 복원
Same Concept, Different Directions (2026)

SAE는 한 입력에서 소수의 잠재 좌표만 활성화하는 오토인코더. x와 y는 각각 이미지·텍스트의 입력 임베딩. σ는 비선형 활성화 함수, z̃는 SAE 인코더와 활성화 함수를 거친 희소 활성값. 디코더에서 각 특징 방향의 활성값 가중합으로 복원 임베딩 x̃와 ỹ 생성. 입력과 복원 임베딩 사이 오차의 최소화를 위한 학습.

특징은 잠재 좌표와 그에 대응하는 방향. 모든 좌표가 반드시 하나의 해석 가능한 개념을 나타낸다는 보장은 없음. Modality split은 동일 의미의 모달리티별 활성 좌표 분리 현상.

같은 범주보다 점수가 높은 다른 범주는 얼마나 자주 존재하는가?

170개 상대 중 하나라도 같은 범주의 점수를 넘은 범주의 비율

이미지 기준텍스트 기준

이미지 기준은 C(A,B)와 C(A,A)의 비교. 이미지 범주 A에 대해 나머지 170개 텍스트 범주 중 하나라도 대각보다 엄격하게 높은 점수를 받는 경우 A를 계수. 텍스트 기준은 C(B,A)와 C(A,A)의 비교. 동점의 초과 집계 제외.

이미지 기준은 전체 95/171, 물체 18/80, 배경 77/91. 텍스트 기준은 전체 86/171, 물체 14/80, 배경 72/91. 물체·배경은 기준 범주의 유형. 상대는 유형과 관계없이 나머지 170개 범주 전체.

쌍을 분모로 센 비율은 이미지 기준 2,399/29,070인 8.25%, 텍스트 기준 2,089/29,070인 7.19%. 본문 그림은 쌍 비율이 아닌 범주 비율. 대표 특징을 공유한 범주도 포함. 사람의 의미 검증에 따른 오류율이나 헝가리안 연결 오류율과는 구분.

RQ1 · 질문 3

양의 동시 등장 상관을 0으로 조정하면 특징 상관점수가 낮아지는가?

원본동시 등장 상관을 0으로 조정

이미지 범주 기준

텍스트 범주 기준

상자 25–75% · 가로선 중앙값 · 수염 최솟값–최댓값 · 평균

각 범주의 등장률을 유지하며 두 범주의 이미지 주석 상관이 0이 되도록 네 집단의 계산 비중 조정. A와 B의 등장률을 p와 q로 둘 때, 둘 다 없는 집단의 비중 (1−p)(1−q), B만 있는 집단의 비중 (1−p)q, A만 있는 집단의 비중 p(1−q), 둘 다 있는 집단의 비중 pq. 원본 이미지·캡션 짝, 활성값, SAE, 대표 특징의 유지. 범주 쌍마다 별도 비중 적용.

양의 주석 상관을 가진 쌍에만 조정 적용. 원래 상관이 0 이하인 쌍의 원본 유지. 구간 경계는 조정 이전의 원본 주석 상관 기준. 두 방향의 전체 비교 쌍 구성에 따른 동일 분포.
