Same Concept, Different Directions (2026)

SAE는 한 입력에서 소수의 잠재 좌표만 활성화하는 오토인코더. x와 y는 각각 이미지·텍스트의 입력 임베딩. σ는 비선형 활성화 함수, z̃는 SAE 인코더와 활성화 함수를 거친 희소 활성값. 디코더에서 각 특징 방향의 활성값 가중합으로 복원 임베딩 x̃와 ỹ 생성. 입력과 복원 임베딩 사이 오차의 최소화를 위한 학습.

특징은 잠재 좌표와 그에 대응하는 방향. 모든 좌표가 반드시 하나의 해석 가능한 개념을 나타낸다는 보장은 없음. Modality split은 동일 의미의 모달리티별 활성 좌표 분리 현상.

RQ1. coactivation correlation의 한계와 개선

활성값의 상관관계(coactivation correlation)가 실제 의미 대응을 정확히 반영하지 못하는 경우는 언제이며, 이를 어떻게 개선할 수 있을까?

RQ2. 일대일 대응의 한계와 대안

같은 개념을 나타내는 이미지·텍스트 특징의 관계를 1 대 1로 표현하기 어려운 경우*는 언제이며, 이를 어떤 대응 방식으로 해결할 수 있을까?

* 한 개념이 여러 특징에 나뉘거나(feature splitting), 여러 개념이 한 특징을 공유하는(feature merging) 경우

RQ1은 coactivation correlation이 의미 대응을 잘못 나타내는 조건과 점수의 개선 방법을 검토한다. RQ2는 같은 개념을 나타내는 모달리티별 특징의 관계를 일대일로 표현하기 어려운 조건과 대안적 대응 방식을 검토한다. 별표는 검토할 경우의 예시이며 해결 여부를 단정하지 않는다.

coactivation correlation의 한계와 개선

  1. 1-1

  2. 1-2

    대응에 미치는 영향 확인: 다른 개념의 특징과 계산한 coactivation correlation이 같은 개념의 특징과 계산한 점수보다 높은 경우(e.g., 눈-눈 < 눈-스키)는 얼마나 자주 발생하는가?

  3. 1-3

    개선 가능성 확인: 데이터에서 두 개념의 양의 동시 등장 상관을 0으로 통제하면, 서로 다른 개념의 특징 사이의 coactivation correlation이 낮아지는가?

지난 RQ1 실험에서 확인한 세 질문이다. 1-1은 Data correlation 구간별 특징 coactivation correlation 분포를 비교한다. 1-2는 같은 범주의 점수보다 다른 범주의 점수가 높은 쌍의 비율을 이미지 기준과 텍스트 기준으로 각각 평가한다. 1-3은 모델과 특징을 고정하고 각 개념의 등장 비율을 유지한 채 표본의 계산 비중을 조정하여 양의 동시 등장 상관을 0으로 만든 조건을 원본과 비교한다. 가림이나 재학습을 통한 통제와 구분한다.

    (coactivation correlation)를 Data correlation 및 동일 범주 점수와 비교

* 대표 특징 선택에 사용한 AUROC

두 집단에서 각각 뽑은 원본의 활성값이 가림본보다 높은 비율

AUROCj,c = P(zj(Xc+) > zj(Xc−)) + ½ P(zj(Xc+) = zj(Xc−))

  • 비교 대상: Xc+는 개념 c가 포함된 원본, Xc−는 해당 개념을 가린 입력, zj는 SAE 특징 j의 활성값
  • 해석: 0.5는 무작위 수준, 1은 완전한 구별

기존 단일 특징 실험의 설정이다. COCO-Stuff 주석으로 이미지별 범주 존재 여부를 이진 벡터로 만들고 Pearson 상관계수를 계산했다. 이미지 SAE와 텍스트 SAE를 따로 학습했다. 이미지에서는 해당 범주의 주석 영역을 흰색으로 가리고, 텍스트에서는 사전으로 찾은 해당 범주 표현을 토크나이저의 UNK 토큰으로 가렸다. 텍스트의 원본·가림 비교는 해당 표현이 검출되는 캡션을 사용한다.

각 모달리티와 범주에서 원본 활성값 집단과 가림 활성값 집단의 AUROC를 계산해 가장 높은 특징을 선택했다. AUROC는 같은 이미지의 전후만 비교하는 비율이 아니라 두 집단의 모든 교차 조합에 대한 순위 통계이며 동률에는 0.5를 부여한다. 특징 선택 후 원본 쌍에서 활성값의 Pearson 상관계수를 계산한다. 학습과 제거 자료로 특징을 확인하는 절차를 구분하며 제거 자료로 SAE를 재학습하지 않는다.

특징을 선택하는 기준을 어떻게 바꿔볼 수 있을까?

기존 원본·가림 AUROC에 세 가지 선택 기준을 추가하여 결과 비교

1. 평균 활성값 감소량 [1]

Sj = (1/N) ∑i=1N [zj(xi) − zj(xi가림)]

해당 개념이 있는 같은 표본의 가림 전후 활성값 차이를 평균하여, 감소량이 큰 특징부터 선택

2. 단일 좌표 분류 손실 [2]

특징 하나의 활성값으로 개념의 존재 여부를 예측하는 분류기를 학습 데이터의 80%로 각각 학습하고, 나머지 20%에서 예측 오류가 작은 특징부터 선택

3. 개념의 존재 여부를 예측하는 데 기여한 정도 [3]

Sj = (E[zj | y=1] − E[zj | y=0]) × (w⊤dj)

원본 임베딩으로 개념의 존재 여부를 예측하는 분류기를 학습한 뒤, ‘개념 유무에 따른 평균 활성값 차이 × 해당 특징이 분류 점수에 미치는 영향’이 큰 특징부터 선택

zj는 SAE 특징 j의 활성값 · y는 개념 존재 여부(있음 1, 없음 0)
w는 원본 임베딩 분류기의 가중치 · dj는 SAE 특징 j의 방향 벡터 · N은 원본·가림 쌍 수

[1] SAEBench (2025)의 평균 차이 기준을 원본·가림 비교에 적용 (논문은 개념 있음·없음 비교)
[2] Scaling and evaluating sparse autoencoders (2024), §4.2의 단일 좌표 분류 평가 참고
[3] Evaluating Sparse Autoencoders on Targeted Concept Erasure Tasks (2024), §3.1의 기여도 식 참고

평균 감소량은 개념이 있는 표본에서만 계산하며 감소량의 부호를 유지한다. 단일 좌표 분류기는 학습 자료에서 적합하고 별도 조정 자료의 교차엔트로피로 특징을 선택한다. 기여도는 원본 임베딩 분류기의 선형 점수에 대한 기여이며 확률 변화량 자체는 아니다. 이미지에서는 주석의 존재 여부, 텍스트에서는 사전으로 판정한 언급 여부를 사용한다. 두 분류 기반 방법은 개념이 없을 때 활성화되는 특징도 선택할 수 있다. 평가 자료의 정답은 선택에 사용하지 않는다.

시사점: 특징 하나로 놓치는 개념 정보를 여러 특징이 보완하므로, 개념을 특징 집합으로 표현할 근거. 다만 이미지의 원본·가림 구별은 개선 후에도 낮은 수준으로, 개념 제거에 대한 반응까지 충분히 포착한 것은 아님

존재 구별과 원본·가림 구별을 분리했다. 존재 구별은 분류기의 예측 확률, 가림 구별은 1개일 때 활성값 자체와 5개일 때 음이 아닌 가중합으로 평가한다. 배경 특징 수 추가 비교는 동일 배경 90개 범주이며 기여도 기준 5개 .733, 8개 .765, 16개 .807, 64개 .865다. 집합 표현의 이점이 모달리티 간 대응 개선을 입증하지는 않는다.

금주 추가 분석 · RQ2

같은 대표 특징을 공유하는 개념도 여러 특징을 사용하면 구별할 수 있을까?

  • 질문: 같은 특징이 대표로 선택된 두 개념도, 다른 특징을 함께 사용하면 구별할 수 있는가?
  • 실험: 같은 대표 activation을 공유하는 두 범주 A·B의 25쌍(예: 스키·스노보드, 모래·바다)에 대해, activation으로 A만 있는 이미지와 B만 있는 이미지를 구별하는 분류기를 학습
  • AUROC: A를 양성으로 두었을 때, A 이미지에 B 이미지보다 높은 예측 점수를 주는 비율 (동점은 0.5로 계산)

개념 예측 기여도로 특징 선택 · 네 선택 기준 공통 쌍 · 상자 25–75% · 중앙선 중앙값 · 수염 최솟값–최댓값 · ◆ 평균

  • 결과: 대표 특징 하나를 공유하더라도, 추가 특징을 사용하면 두 개념을 더 잘 구별
  • 시사점: 대표 특징 번호가 같다는 사실만으로 두 개념의 표현이 같다고 판단하기 어려움

원본 A만 존재하고 B가 없는 표본과 B만 존재하고 A가 없는 표본을 비교했다. 공통 25쌍은 네 선택 기준에서 대표 공유와 세 분류 조건 평가가 모두 가능한 쌍의 교집합이다. 같은 개념 표현이 여러 좌표에 분산됐다는 해석을 뒷받침하지만 모달리티 간 다대다 대응 자체를 검증한 결과는 아니다.

이번 주 Takeaway와 다음 주 계획

이번 주에 알게 된 점

  • 특징 선택 기준을 바꿔도 같은 범주보다 다른 범주의 coactivation correlation이 높은 현상이 남음
  • 개념을 특징 하나로 표현하는 데 한계가 있으며, 여러 특징을 사용하면 구별 성능이 개선됨
  • 배경의 존재를 잘 예측하는 것과 배경 자체의 제거에 반응하는 것은 다름
  • 대표 activation 하나의 원본·가림 구별은 텍스트보다 이미지에서 어려움 (이미지 평균 AUROC 0.571–0.576 · 텍스트 0.908–0.924)

실마리

  • RQ1 관련 실마리
    관찰: 대응 문제는 AUROC가 낮은 범주에 집중됐으며, 이미지 대표 activation의 원본·가림 구별 능력이 텍스트보다 낮았음
    가능한 이유 1: 이미지의 한 개념을 나타내는 정보가 여러 activation에 나뉘어, 하나만 선택하면 일부 정보를 놓칠 가능성
    가능한 이유 2: 선택한 이미지 activation이 해당 개념뿐 아니라 주변 물체·배경에도 반응할 가능성
    대응과의 연결: 이미지 대표 activation이 해당 개념을 충분히 반영하지 못하면, 같은 개념의 텍스트 activation과도 coactivation correlation이 낮아질 가능성
  • RQ2: 하나의 activation을 공유하는 개념도 activation 집합은 일부가 겹치지 않으며, 여러 activation을 사용하면 더 잘 구별된다는 근거
  • 두 RQ의 연결: 개념을 activation 하나로 대표하는 방식이 구별과 대응 모두의 한계일 가능성. activation 집합 간 대응이 도움이 될 수 있으나 개선 여부는 아직 미확인

다음 주 계획

  • 이미지에서는 activation 하나로 개념을 잘 구별하지 못하는 이유 분석
  • activation 집합 간 대응으로 같은 개념의 이미지·텍스트를 더 잘 연결할 수 있는지 평가

원본·가림 AUROC는 선택한 특징 1개의 검증 성능 평균이다. 이미지 영역 가림과 텍스트 표현 가림은 서로 다른 조작이므로 차이를 SAE 품질만의 차이로 단정하지 않는다. 여러 activation에 정보가 나뉘거나 주변 개념에 반응한다는 설명은 가설이며 직접 검증이 필요하다. 공유 대표 범주의 상위 특징은 부분적으로 겹치며 완전히 분리된다는 뜻은 아니다. 집합의 개념 구별 향상은 집합 간 의미 대응 향상의 증거와 구분한다.

방향키로 이동

대표 특징 AUROC와 동일 범주의 coactivation correlation
