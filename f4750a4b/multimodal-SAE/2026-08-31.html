Cross-Modal SAE Feature Correspondence의 실제 구조 검증

기존 연구는 이미지와 텍스트에서 같은 의미를 나타내는 feature direction이 서로 다를 수 있다는 cross-modal feature heterogeneity를 제시했습니다. 이번 후속 연구의 첫 단계에서는 기존 대응 절차가 사용한 coactivation correlation과 1:1 대응 가정이 실제 embedding에서 어떤 경우에 실패하는지 확인하려 합니다.

이 문서에서는 두 가지 구조적 질문만 다룹니다. RQ1은 높은 coactivation correlation이 실제로 같은 의미를 나타내는 feature pair를 찾는지 검증합니다. RQ2는 같은 category를 표현하고 상대 모달리티의 activation을 설명하는 데 feature가 하나면 충분한지, 아니면 여러 feature가 필요한지 검증합니다. 새로운 대응 점수나 matching 방법의 설계와 성능 비교는 이 결과를 확인한 뒤 별도의 후속 단계에서 다루려 합니다.

coactivation correlation 행렬 \(\mathbf C\)의 문제

함께 활성화된다는 사실만으로 같은 정보를 나타낸다고 결론 내릴 수 없습니다

강아지와 잔디를 예로 들겠습니다. 강아지가 잔디 위에 자주 등장하면 이미지의 잔디 feature와 텍스트의 강아지 feature도 높은 correlation을 얻을 수 있습니다.

다시 말해서, 의미적으로 공통된 부분이 전혀 없음에도 함께 자주 등장한다는 이유만으로 서로 다른 두 feature가 높은 correlation을 얻는 문제가 있을 수 있습니다.

실험에서는 같은 category를 나타내는 feature pair와 서로 다른 category를 나타내지만 자주 함께 등장하는 feature pair의 correlation을 비교하려 합니다. 이어서 다른 category의 존재 여부를 통제하면 서로 다른 category의 feature pair가 얻는 correlation이 낮아지는지 확인하려 합니다.

실제 실험에서는 강아지와 잔디에만 한정하지 않고, 여러 객체 개념과 배경 개념에 같은 분석을 적용하려 합니다. 사용할 데이터와 annotation은 RQ1의 공통 실험 설정에서 설명합니다.

Hungarian 1:1 대응행렬 \(\mathbf P\)의 문제

같은 개념을 두 모달리티가 같은 수의 feature로 표현한다고 가정할 수 없습니다

하나의 의미에 대응되는 SAE feature가 각 모달리티에 하나씩만 존재한다고 가정할 수 없습니다.

강아지를 예로 들면, 이미지 SAE에서는 강아지의 얼굴, 털과 몸의 형태를 나타내는 여러 feature가 함께 강아지 정보를 구성할 수 있습니다. 텍스트 SAE에서도 dog, puppy와 canine처럼 범위와 세부 의미가 다른 여러 feature가 강아지와 관련된 정보를 구성할 수 있습니다.

따라서 이미지와 텍스트의 feature는 1:1이 아니라 서로 다른 수와 구성의 feature set이 연결되는 \(N{:}M\) 관계일 수 있습니다. 일부 feature는 한쪽 모달리티에만 필요한 정보를 나타내어 상대 모달리티에서 대응되는 feature가 없을 수도 있습니다.

후속 연구의 첫 단계에서는 같은 category를 설명하는 데 각 모달리티에서 몇 개의 feature가 필요한지 측정하고, 상대 모달리티의 feature를 하나보다 많이 사용해야 activation을 설명할 수 있는지 확인하려 합니다.

1

기존 연구는 다른 feature direction을 보존한 뒤 latent coordinate를 맞췄습니다

기존 연구의 출발점과 대응 절차를 원 논문의 표기로 정리합니다.

출발점은 cross-modal feature heterogeneity입니다

기존 연구는 같은 의미 개념이라도 image embedding의 feature direction \(\boldsymbol\phi_i\)와 text embedding의 feature direction \(\boldsymbol\psi_i\)가 다를 수 있다고 보았습니다. 이를 cross-modal feature heterogeneity라고 정의했습니다. 하나의 SAE가 서로 다른 두 direction을 같은 latent coordinate에 억지로 담으면 feature reconstruction이 나빠질 수 있으므로, 이미지와 text embedding에 별도의 SAE를 학습했습니다.

이 문서에서 SAE feature가 뜻하는 것 SAE feature는 SAE decoder의 한 열이 나타내는 embedding 공간의 direction입니다. 입력마다 그 feature가 얼마나 나타나는지는 해당 latent coordinate의 activation \(\tilde z_i\)로 측정합니다.

기존 대응 절차는 coactivation correlation 행렬 \(\mathbf C\)를 계산한 뒤, 대응행렬 \(\mathbf P\)로 모달리티 간 feature pair를 구합니다

먼저 짝을 이룬 image embedding \(\mathbf x\)와 text embedding \(\mathbf y\)를 각각의 SAE에 넣어 latent activation \(\tilde{\mathbf z}(\mathbf x)\)와 \(\tilde{\mathbf z}(\mathbf y)\)를 얻습니다. 모든 image feature와 text feature의 coactivation correlation을 계산하여 coactivation correlation 행렬 \(\mathbf C\)를 만듭니다. 그런 다음 \(\mathbf C\)에서 전체 correlation의 합이 가장 커지는 1:1 feature pair를 선택하고, 그 결과를 대응행렬 \(\mathbf P\)로 나타냅니다.

\[ \mathbf C_{\mathrm{raw}} :=\operatorname{Corr}\!\left(\tilde{\mathbf z}(\mathbf x),\tilde{\mathbf z}(\mathbf y)\right), \qquad c^{\mathrm{raw}}_{i,j}:=[\mathbf C_{\mathrm{raw}}]_{i,j}. \]

기존 논문에서는 이 행렬을 \(\mathbf C\)라고 썼습니다. 이 문서에서는 기존 correlation matrix와 새 점수행렬을 구분하기 위해 기존 행렬을 \(\mathbf C_{\mathrm{raw}}\)라고 씁니다. \(c^{\mathrm{raw}}_{i,j}\)가 클수록 image feature \(i\)와 text feature \(j\)가 같은 의미를 나타낼 가능성이 높다고 보았습니다.

다음으로 모든 feature를 하나씩 짝짓는 permutation matrix \(\hat{\mathbf P}\)를 구했습니다.

\[ \hat{\mathbf P} \in \underset{\mathbf P\in\mathcal P_m}{\arg\max} \left\langle\mathbf C_{\mathrm{raw}},\mathbf P\right\rangle =\operatorname{tr}(\mathbf C_{\mathrm{raw}}^{\top}\mathbf P), \]

여기서 \(\mathcal P_m\)은 \(m\times m\) permutation matrix의 집합입니다. Hungarian algorithm은 전체 correlation의 합이 가장 커지도록 image feature와 text feature를 1:1로 연결합니다. 이 permutation은 텍스트 SAE의 latent coordinate만 다시 배치하므로 두 모달리티의 decoder direction은 바꾸지 않습니다.

2

후속 연구는 대응 점수와 대응 구조의 가정을 따로 검증합니다

대응 점수행렬 \(\mathbf C_{\mathrm{raw}}\)의 문제와 permutation 대응행렬 \(\mathbf P\)의 문제는 원인이 다르므로 실험과 방법을 분리합니다.

대응 점수행렬 \(\mathbf C_{\mathrm{raw}}\)

가정

image feature와 text feature의 activation이 함께 변하면 두 feature가 같은 정보를 나타낸다고 가정합니다.

문제

두 feature가 서로 다른 정보를 나타내더라도 두 정보가 데이터에서 자주 함께 등장하면 correlation이 높아집니다. 따라서 높은 correlation만으로는 두 feature가 실제로 같은 의미의 정보를 나타내는지, 아니면 의미적으로 공통된 정보 없이 데이터에서 자주 함께 나타나는지를 구분할 수 없습니다.

구체적인 오류강아지가 잔디 위에 자주 등장하면 이미지의 grass feature와 텍스트의 dog feature가 실제로 같은 정보를 나타내지 않아도 높은 점수를 얻습니다.
permutation 대응행렬 \(\mathbf P\)

가정

모든 image feature와 text feature는 각각 하나의 상대 모달리티 feature와 반드시 연결된다고 가정합니다.

문제

같은 개념을 이미지와 텍스트가 서로 다른 수와 구성의 feature로 표현할 수 있습니다. 한쪽 모달리티에만 있는 정보도 있으므로 모든 feature를 연결하면 잘못된 짝을 만들 수 있습니다.

구체적인 오류이미지의 dog face, dog fur, dog shape가 텍스트의 dog, puppy와 함께 강아지 정보를 구성하면 실제 대응은 3:2일 수 있습니다.
두 문제를 합쳐서 해석하지 않습니다 대응 점수를 고쳐도 1:1 제약은 남습니다. 반대로 연결 수만 늘리면 의미적으로 공통된 정보가 없지만 데이터에서 자주 함께 나타나서 높은 correlation을 얻은 feature pair까지 더 많이 선택할 수 있습니다. 따라서 RQ1은 대응 점수행렬을 검증하고, RQ2는 같은 점수를 사용한 상태에서 대응행렬의 제약을 검증합니다.
3

RQ1. coactivation correlation은 의미적으로 공통점이 없는 feature pair에도 두 개념이 자주 함께 등장한다는 이유만으로 높은 점수를 주는가?

COCO 2017로 학습한 SAE와 이미지의 객체 및 배경 영역을 pixel 단위로 표시한 annotation을 사용하여, 개별 feature pair의 점수 오류와 최종 matching의 오류를 차례로 확인하려 합니다. 이어서 다른 개념의 영향을 통제하면 두 오류가 줄어드는지 검증하려 합니다.

COCO-Stuff 데이터셋과 annotation

COCO-Stuff는 COCO 2017의 각 이미지에 어떤 object가 있는지와 어떤 주변 배경이 있는지를 표시한 데이터셋입니다. 사람, 강아지와 자동차 같은 object는 80개의 thing category로 구분하고, 잔디, 하늘과 도로 같은 주변 배경은 91개의 stuff category로 구분합니다. 이 연구에서는 이 annotation을 이용하여 각 이미지에 어떤 thing과 stuff가 함께 등장하는지 기록하려 합니다.

RQ1에서 검증하려는 세 질문

세 질문은 coactivation correlation의 문제를 단계적으로 확인합니다. 먼저 개별 feature pair의 점수에서 오류가 실제로 나타나는지 확인합니다. 다음으로 이 점수 오류가 최종 Hungarian matching의 오류로 이어지는지 확인합니다. 마지막으로 다른 개념이 자주 함께 등장하는 현상을 통제했을 때 두 오류가 줄어드는지 확인하여, 함께 등장하는 빈도가 오류의 원인인지 검증합니다.

질문 1. 서로 다른 category가 데이터에서 자주 함께 등장하면, 서로 다른 category의 feature pair가 같은 category의 feature pair보다 높은 coactivation correlation을 얻는가?

질문 2. 서로 다른 category의 feature pair가 더 높은 점수를 얻으면, 기존 Hungarian matching이 실제로 서로 다른 category의 feature를 연결하는가?

질문 3. COCO-Stuff annotation으로 다른 category의 영향을 통제하면, 다른 category의 feature pair가 같은 category의 feature pair보다 높은 점수를 얻는 사례와 Hungarian matching이 서로 다른 category의 feature를 연결하는 사례가 줄어드는가?

공통 실험 설정

COCO 2017의 짝지어진 이미지와 문장 embedding으로 이미지 SAE와 텍스트 SAE를 학습하려 합니다. 위에서 정의한 image-level category 존재 표지와 caption의 category 언급 표지를 사용하면 dog와 grass, car와 road처럼 서로 다른 category가 함께 등장하는 빈도를 계산할 수 있습니다.

각 SAE feature가 특정 category가 있는 표본과 없는 표본을 얼마나 잘 구분하는지는 Area Under the Receiver Operating Characteristic Curve (AUROC)로 측정하려 합니다. AUROC는 기존 논문의 리부탈 실험에서도 각 feature가 어떤 category에 대응하는지 확인할 때 사용했습니다.

개념 \(a\)에서 AUROC가 가장 높은 image feature를 \(i^*(a)\), text feature를 \(j^*(a)\)로 정합니다. feature를 고르고 규제 강도를 정하는 학습 및 검증 표본과 최종 점수를 보고하는 시험 표본은 분리하려 합니다.

실험 1

서로 다른 개념이 자주 함께 등장하면 동일한 개념보다 유사하거나 높은 correlation을 얻는 경우가 있는가?

확인하려는 이유

기존 대응 점수행렬의 첫 번째 실패는 개별 feature pair의 순위가 뒤집히는 현상입니다. 이 현상이 실제 embedding에서 발생해야 대응 점수를 바꿀 근거가 생깁니다.

실험 방법

개념(object) \(a\)의 image feature \(i^*(a)\)와 텍스트 개념 feature \(j^*(b)\) 사이의 correlation을 계산하려 합니다. 서로 같은 개념을 나타내는 feature pair의 점수 \(c^{\mathrm{raw}}_{i^*(a),j^*(a)}\)보다 서로 다른 개념을 나타내는 feature pair의 점수가 큰 사례를 셉니다.

다른 개념의 최고값만 고르면 비교 대상이 많아서 우연히 큰 값이 나올 수 있습니다. 이를 고려하기 위해 개념 빈도와 feature AUROC가 비슷한 다른 개념을 짝지은 permutation 기준선을 함께 계산하려 합니다.

같은 개념을 나타내는 feature pair가 전체 순위에서 몇 위인지와 상위 \(k\)개 안에 포함되는 비율도 보고하려 합니다.

예상 결과

dog와 grass처럼 서로 다른 의미를 나타내지만 함께 등장하는 빈도가 높은 개념에서는, 다른 개념의 feature pair가 같은 개념의 feature pair보다 높은 correlation을 얻는 사례가 permutation 기준선보다 자주 발생할 것으로 예상합니다.

이러한 사례의 비율이 두 개념의 동시 등장 빈도와 함께 증가하면, 의미적으로 공통된 정보가 없는 feature pair가 자주 함께 나타난다는 이유만으로 높은 correlation을 얻었을 가능성을 확인할 수 있습니다.

두 개념이 함께 등장하는 빈도가 낮은데도 다른 개념의 feature pair가 더 높은 점수를 얻는다면 그 원인을 추가로 조사하려 합니다.

실험 2

다른 개념의 feature pair가 더 높은 점수를 얻으면 Hungarian matching이 서로 다른 개념의 feature를 연결하는가?

확인하려는 이유

일부 feature pair의 순위가 뒤집혀도 전체 최적화가 올바른 짝을 고를 수 있습니다. 따라서 점수 수준의 오류가 최종 대응행렬을 실제로 바꾸는지 확인해야 합니다.

실험 방법

기존 대응 점수행렬 \(\mathbf C_{\mathrm{raw}}\)에 Hungarian algorithm을 적용하려 합니다.

학습 표본에서 정한 AUROC 기준을 넘는 feature만 개념 대표 feature로 사용하고, 각 feature에는 AUROC가 가장 높은 개념을 대표 개념으로 붙입니다.

두 현상이 함께 증가하지 않으면 개별 feature pair의 점수 오류가 최종 matching 오류로 이어진다는 해석을 지지하지 않습니다.

목표

기존 방법에서는 correlation을 image feature와 text feature의 대응 정도를 나타내는 점수로 사용했습니다. 그러나 두 feature가 서로 다른 의미를 나타내더라도 두 개념이 데이터에서 자주 함께 등장하면 correlation이 높아질 수 있습니다. 이 문제가 실제로 나타난다면, 새 대응 점수는 같은 의미를 공유하는 feature pair에는 높은 점수를 유지하고, 의미는 다르지만 자주 함께 등장하는 feature pair의 점수는 낮춰야 합니다.

이를 위해 새 대응 점수는 image feature와 text feature가 단순히 함께 활성화되는 정도만 측정하지 않아야 합니다. 같은 모달리티의 다른 feature들이 이미 설명하는 부분을 고려한 뒤에도 image feature와 text feature 사이에 남는 관계가 클수록 높은 점수를 주어야 합니다.

여기서 주의할 점이 있습니다. 하나의 의미가 여러 feature로 나뉘어 표현될 수 있으므로, 서로 겹치는 정보를 줄인다는 이유로 같은 의미를 구성하는 feature까지 모두 제거하면 안 됩니다. 예를 들어 이미지의 강아지 얼굴, 털과 형태를 나타내는 feature는 서로 겹치는 부분이 있더라도 함께 강아지라는 의미를 구성할 수 있습니다.

아이디어의 직관적 설명

핵심은 image feature와 text feature를 하나씩 따로 비교하던 기존 점수를, 같은 모달리티의 여러 feature를 함께 고려한 예측 기여로 바꾸는 것입니다.

먼저 여러 image feature의 activation으로 하나의 text feature activation을 예측합니다. 예측값은 각 image feature의 activation에 서로 다른 coefficient를 곱한 뒤 모두 더해서 만듭니다. 학습 과정에서는 이 예측값이 실제 text feature activation에 가까워지도록 모든 coefficient를 동시에 정합니다.

여러 feature를 동시에 사용하는 이유는 각 feature가 예측에 새로 보태는 정보가 있는지 확인하기 위해서입니다. 예를 들어 image의 강아지 feature와 잔디 feature가 모두 text의 강아지 feature와 높은 correlation을 가진다고 가정합니다. image의 강아지 feature만으로 text의 강아지 activation을 이미 잘 예측한다면, 잔디 feature를 추가해도 예측 오차는 거의 줄어들지 않습니다. 특히 강아지는 없고 잔디만 있는 표본에서 잔디 feature의 coefficient를 크게 두면 text의 강아지 activation을 잘못 높게 예측합니다. 따라서 학습 과정에서는 잔디 feature의 coefficient를 낮추는 방향으로 조정할 수 있습니다.

반면 같은 의미를 나누어 표현하는 feature는 추가 설명력이 있으면 남을 수 있습니다. 예를 들어 image의 강아지 얼굴 feature만으로 설명하지 못한 text의 강아지 activation을 강아지 털 feature가 추가로 설명한다면, 강아지 털 feature의 coefficient를 높였을 때 예측 오차가 줄어듭니다. 이 경우 두 image feature는 모두 text의 강아지 feature를 설명하는 feature로 평가할 수 있습니다.

이 구분은 서로 다른 개념이 따로 나타나는 표본이 있을 때 가능합니다. 강아지와 잔디가 모든 표본에서 항상 함께 나타난다면 regression도 두 feature의 역할을 구분할 수 없습니다. Ridge regression은 큰 coefficient에 비용을 부과하여 추가 설명력이 작은 feature의 coefficient를 낮추는 데 도움을 주지만, 관측 데이터만으로 구분할 수 없는 관계까지 해결하지는 못합니다.

이 아이디어에서 후보 대응 점수행렬은 다음 네 단계로 유도됩니다. 먼저 기존 coactivation correlation을 한 feature만 사용하는 regression coefficient로 다시 씁니다. 다음으로 image에서 text를 예측하는 방향과 text에서 image를 예측하는 방향에서 여러 feature를 함께 고려합니다. 마지막으로 두 방향의 결과를 하나의 대칭적인 대응 점수행렬로 결합합니다.

1. 기존 coactivation correlation을 한 feature만 사용하는 regression coefficient로 다시 씁니다

짝지어진 \(N\)개 표본에서 이미지와 텍스트 latent activation을 열별로 표준화하고, 이를 각각 \(\tilde{\mathbf Z}_{\mathrm I}\in\mathbb R^{N\times m}\)와 \(\tilde{\mathbf Z}_{\mathrm T}\in\mathbb R^{N\times m}\)로 놓습니다. 기존 correlation matrix는 다음과 같습니다.

\[ \mathbf C_{\mathrm{raw}} =\frac{1}{N}\tilde{\mathbf Z}_{\mathrm I}^{\top}\tilde{\mathbf Z}_{\mathrm T}. \]

표준화한 image feature \(i\) 하나로 text feature \(j\)를 예측하는 단변량 linear regression을 쓰면 다음과 같습니다.

\[ \hat\beta_{i,j} :=\underset{\beta}{\arg\min}\; \frac{1}{N} \left\| [\tilde{\mathbf Z}_{\mathrm T}]_{:,j} -\beta[\tilde{\mathbf Z}_{\mathrm I}]_{:,i} \right\|_2^2 =\frac{1}{N} [\tilde{\mathbf Z}_{\mathrm I}]_{:,i}^{\top} [\tilde{\mathbf Z}_{\mathrm T}]_{:,j} =c^{\mathrm{raw}}_{i,j}. \]

따라서 기존 대응 점수는 모든 feature pair에 독립적인 단변량 regression을 적용한 결과로 볼 수 있습니다.

2. 모든 image feature를 함께 사용하여 text feature를 예측합니다

먼저 \(m\)개의 image SAE feature를 동시에 사용하여 \(m\)개의 text SAE feature를 각각 예측하려 합니다. 기존 correlation은 image feature 하나와 text feature 하나만 비교했지만, 이 회귀는 한 image feature의 예측 기여가 다른 image feature의 정보와 겹치는지도 함께 고려합니다.

서로 비슷한 feature가 많을 때 regression coefficient가 불안정해지지 않도록 계수 제곱합에 비용을 부과하는 ridge regression을 사용합니다. image에서 text 방향의 coefficient matrix는 다음 목적함수로 정의합니다.

\[ \mathbf A_{\lambda_{\mathrm I}}^{\mathrm{I\rightarrow T}} :=\underset{\mathbf A}{\arg\min}\; \frac{1}{N} \left\| \tilde{\mathbf Z}_{\mathrm T} -\tilde{\mathbf Z}_{\mathrm I}\mathbf A \right\|_F^2 +\lambda_{\mathrm I}\|\mathbf A\|_F^2. \]

image feature끼리의 correlation matrix를 \(\mathbf C_{\mathrm{II}}\)라고 둡니다. 위 목적함수를 coefficient matrix \(\mathbf A\)로 미분한 뒤 0으로 놓으면 다음 식을 얻고, 이를 풀면 image에서 text 방향의 coefficient matrix가 나옵니다.

\[ \mathbf C_{\mathrm{II}} :=\frac{1}{N}\tilde{\mathbf Z}_{\mathrm I}^{\top}\tilde{\mathbf Z}_{\mathrm I}, \qquad (\mathbf C_{\mathrm{II}}+\lambda_{\mathrm I}\mathbf I) \mathbf A_{\lambda_{\mathrm I}}^{\mathrm{I\rightarrow T}} =\mathbf C_{\mathrm{raw}}, \] \[ \mathbf A_{\lambda_{\mathrm I}}^{\mathrm{I\rightarrow T}} =(\mathbf C_{\mathrm{II}}+\lambda_{\mathrm I}\mathbf I)^{-1}\mathbf C_{\mathrm{raw}}. \]

원소 \(A^{\mathrm{I\rightarrow T}}_{i,j}\)는 모든 image feature를 함께 사용하여 text feature \(j\)를 예측할 때 image feature \(i\)에 부여되는 표준화 regression coefficient입니다. 이 계수는 다른 image feature가 이미 설명한 정보를 고려한 뒤 남는 예측 기여를 나타냅니다. 예를 들어 이미지의 강아지 feature가 텍스트의 강아지 activation을 이미 설명한다면 이미지의 잔디 feature가 추가로 얻는 계수는 기존 correlation보다 작아질 수 있습니다. 다만 이 계수만으로 두 feature의 의미가 같다고 결론 내리지는 않습니다.

3. 모든 text feature를 함께 사용하여 image feature를 예측합니다

두 모달리티의 역할을 바꾸어 text feature 전체로 image feature 전체를 예측합니다. text에서 image 방향의 coefficient matrix는 다음 목적함수로 정의합니다.

\[ \mathbf A_{\lambda_{\mathrm T}}^{\mathrm{T\rightarrow I}} :=\underset{\mathbf A}{\arg\min}\; \frac{1}{N} \left\| \tilde{\mathbf Z}_{\mathrm I} -\tilde{\mathbf Z}_{\mathrm T}\mathbf A \right\|_F^2 +\lambda_{\mathrm T}\|\mathbf A\|_F^2. \]

text feature끼리의 correlation matrix를 \(\mathbf C_{\mathrm{TT}}\)라고 둡니다. 위 목적함수를 coefficient matrix \(\mathbf A\)로 미분한 뒤 0으로 놓고 풀면 다음 결과를 얻습니다.

\[ \mathbf C_{\mathrm{TT}} :=\frac{1}{N}\tilde{\mathbf Z}_{\mathrm T}^{\top}\tilde{\mathbf Z}_{\mathrm T}, \qquad (\mathbf C_{\mathrm{TT}}+\lambda_{\mathrm T}\mathbf I) \mathbf A_{\lambda_{\mathrm T}}^{\mathrm{T\rightarrow I}} =\mathbf C_{\mathrm{raw}}^{\top}, \] \[ \mathbf A_{\lambda_{\mathrm T}}^{\mathrm{T\rightarrow I}} =(\mathbf C_{\mathrm{TT}}+\lambda_{\mathrm T}\mathbf I)^{-1}\mathbf C_{\mathrm{raw}}^{\top}. \]

원소 \(A^{\mathrm{T\rightarrow I}}_{j,i}\)는 모든 text feature를 함께 사용하여 image feature \(i\)를 예측할 때 text feature \(j\)에 부여되는 표준화 regression coefficient입니다. 두 방향은 서로 다른 예측 관계를 측정하므로 규제 강도 \(\lambda_{\mathrm I}\)와 \(\lambda_{\mathrm T}\)도 각각 검증 표본의 예측 오차로 정하려 합니다.

4. 두 방향의 결과를 하나의 후보 대응 점수행렬로 결합합니다

\[ \boxed{ \mathbf C' :=\frac{1}{2} \left( \mathbf A_{\lambda_{\mathrm I}}^{\mathrm{I\rightarrow T}} + (\mathbf A_{\lambda_{\mathrm T}}^{\mathrm{T\rightarrow I}})^{\top} \right)}. \]

새 행렬 \(\mathbf C'\)은 correlation matrix가 아니라 두 방향의 표준화 regression coefficient를 평균한 후보 대응 점수행렬입니다. regression coefficient는 \([-1,1]\)에 제한되지 않으므로 correlation의 크기와 직접 비교하지 않고 feature pair의 상대적인 순위를 정하는 데 사용하려 합니다. 산술평균이 실제로 같은 의미를 나타내는 feature pair에 더 높은 점수를 준다는 보장은 없으므로, RQ1의 구조 검증이 끝난 뒤 수행하는 2단계 방법 검증에서 정방향 계수, 역방향 계수와 평균을 각각 비교하려 합니다.

기존 점수와 정확히 연결되는 특수한 경우 image feature와 text feature가 각 모달리티 안에서 서로 상관되지 않고 \(\lambda=0\)이면 \(\mathbf C_{\mathrm{II}}=\mathbf I\), \(\mathbf C_{\mathrm{TT}}=\mathbf I\)입니다. 이때 \(\mathbf A^{\mathrm{I\rightarrow T}}=\mathbf C_{\mathrm{raw}}\), \((\mathbf A^{\mathrm{T\rightarrow I}})^{\top}=\mathbf C_{\mathrm{raw}}\)이므로 \(\mathbf C'=\mathbf C_{\mathrm{raw}}\)입니다. 새 점수는 기존 점수와 단절된 방법이 아니라, within-modality feature correlation를 추가로 고려한 확장입니다.
양방향 ridge regression이 의미를 자동으로 식별한다고 주장하지 않습니다 양방향 ridge regression은 다른 SAE feature와 겹치는 예측 성분을 줄입니다. 이 성분이 잔디나 실내 같은 문맥에서 비롯되었다면, 의미적으로 공통된 정보가 없는 두 feature가 그 문맥에서 자주 함께 나타나서 얻은 점수는 낮아질 수 있습니다. 그러나 강아지 얼굴과 털처럼 같은 개념의 정보를 나누어 담은 feature도 서로의 계수를 낮출 수 있습니다. 따라서 이 점수를 문맥 통제 방법이라고 단정하지 않고, RQ1 실험 3의 주석 기반 문맥 통제 점수와 같은 개념의 feature pair를 사용한 긍정 대조군을 통해 실제 효과를 판정하려 합니다.
7

방법론 후보 (대응 행렬 \(\mathbf P\)의 확장)

RQ2에서 여러 feature가 필요하거나 상대 모달리티에 대응되는 feature가 없는 경우가 확인된다면, 대응 행렬 \(\mathbf P\)는 Hungarian matching의 일부 제약을 완화하는 방향으로 확장할 수 있을 것으로 예상합니다. 현재 우선 검토하는 후보는 이진 연결을 유지하면서 feature 하나당 연결 수와 대응 없음을 조절할 수 있는 부분 \(b\)-매칭입니다.

permutation matrix가 1:1 대응을 만드는 조건

Hungarian algorithm이 사용하는 permutation matrix의 집합은 다음과 같이 쓸 수 있습니다.

\[ \mathcal P_m =\left\{ \mathbf P\in\{0,1\}^{m\times m}: \mathbf P\mathbf 1=\mathbf 1, \mathbf P^{\top}\mathbf 1=\mathbf 1 \right\}. \]

이 정의에는 세 조건이 있습니다. 모든 연결은 선택하거나 선택하지 않는 이진값입니다. 각 image feature는 정확히 한 개의 text feature와 연결됩니다. 각 text feature도 정확히 한 개의 image feature와 연결됩니다.

RQ2의 결과를 반영할 수 있는 최소 완화 후보

RQ2에서 \(N{:}M\) 대응과 대응 없음이 각각 성능을 개선한다면, 먼저 두 조건을 완화하는 방법을 검토하려 합니다. 각 행과 열이 둘 이상의 연결을 가질 수 있게 하고, 연결 수가 반드시 1이어야 한다는 등식을 최대 연결 수를 나타내는 부등식으로 바꿉니다. 개별 연결을 해석하기 쉽도록 각 원소는 우선 이진값으로 유지하려 합니다. 이 정도의 완화만으로 RQ2에서 관측한 구조를 충분히 표현할 수 있는지는 실험으로 확인해야 합니다.

\[ \mathcal B(K_{\mathrm I},K_{\mathrm T}) :=\left\{ \mathbf P\in\{0,1\}^{m\times m}: \mathbf P\mathbf 1\le K_{\mathrm I}\mathbf 1, \mathbf P^{\top}\mathbf 1\le K_{\mathrm T}\mathbf 1 \right\}. \]

image feature 하나는 최대 \(K_{\mathrm I}\)개의 text feature와 연결되고, text feature 하나는 최대 \(K_{\mathrm T}\)개의 image feature와 연결됩니다. 적절한 연결이 없으면 해당 행이나 열을 0으로 남길 수 있습니다. 이처럼 각 feature의 최대 연결 수를 정하면서 일부 feature는 연결하지 않는 문제를 최대 가중치 부분 \(b\)-매칭이라고 합니다.

불필요한 연결을 줄이기 위한 후보 제약

최대 연결 수만 정하면 점수가 조금이라도 양수인 연결을 상한까지 선택할 수 있습니다. 이를 줄이기 위해 연결 하나를 추가할 때마다 비용을 부과하는 목적함수를 다음과 같이 검토할 수 있습니다.

\[ \boxed{ \hat{\mathbf P} \in \underset{\mathbf P\in\mathcal B(K_{\mathrm I},K_{\mathrm T})}{\arg\max} \left[ \langle\mathbf C',\mathbf P\rangle -\tau\|\mathbf P\|_1 \right]}. \]

첫 번째 항은 대응 점수가 높은 연결을 선택합니다. 두 번째 항은 연결 하나를 추가할 때마다 비용 \(\tau\)를 부과하여 불필요한 연결을 줄입니다. \(\hat{\mathbf P}\)가 binary matrix이므로 \(\|\mathbf P\|_1\)은 전체 연결 수입니다. RQ2 실험 1과 2는 1:1보다 많은 feature가 필요한지 판단하고 \(K_{\mathrm I}\)와 \(K_{\mathrm T}\)의 탐색 범위를 좁히는 데 사용합니다. 실제 상한과 \(\tau\)는 후보값을 직접 바꾸어 별도의 검증 표본에서 정하고, 최종 성능은 사용하지 않은 시험 표본에서 보고하려 합니다.

Hungarian matching이 그대로 포함되는 조건 \(K_{\mathrm I}=K_{\mathrm T}=1\)로 두고 두 부등식을 등식으로 바꾸면 모든 허용 행렬은 permutation matrix가 됩니다. 모든 permutation matrix는 연결 수가 \(m\)으로 같으므로 연결 비용도 상수가 됩니다. 따라서 새 최적화는 기존 Hungarian 문제와 정확히 같아집니다.

대응 행렬과 activation 변환을 분리하는 방안을 검토합니다

부분 \(b\)-매칭으로 얻은 \(\hat{\mathbf P}\)는 어떤 image feature와 text feature가 연결되는지만 나타낼 수 있습니다. permutation matrix는 좌표를 그대로 재배치할 수 있지만, 한 행에 여러 개의 1이 있는 행렬을 activation에 곧바로 곱하면 한 activation이 여러 좌표로 복제되거나 여러 activation이 더해집니다. 따라서 현재 후보에서는 \(\hat{\mathbf P}\) 자체를 activation 변환행렬로 사용하지 않고, 대응 구조와 실제 변환 가중치를 분리하는 편이 적절할 것으로 봅니다.

이 후보를 실제 alignment에 사용할 때는 \(\hat{\mathbf P}\)가 선택한 연결에만 0이 아닌 가중치를 허용하고, 그 가중치를 학습 표본에서 ridge regression으로 구하는 방안을 검토하려 합니다. 이미지에서 텍스트로 activation을 옮기는 가중치 \(\mathbf W^{\mathrm{I\rightarrow T}}\)는 다음과 같이 학습할 수 있습니다.

\[ \hat{\mathbf W}^{\mathrm{I\rightarrow T}} \in\underset{\operatorname{supp}(\mathbf W)\subseteq \operatorname{supp}(\hat{\mathbf P})}{\arg\min} \frac{1}{N}\left\|\tilde{\mathbf Z}_{\mathrm T} -\tilde{\mathbf Z}_{\mathrm I}\mathbf W\right\|_F^2 +\gamma\|\mathbf W\|_F^2. \]

여기서 \(\operatorname{supp}(\mathbf W)\)는 가중치가 0이 아닌 위치의 집합입니다. 위 제약은 대응행렬 \(\hat{\mathbf P}\)가 선택하지 않은 연결의 가중치를 반드시 0으로 둡니다. 텍스트에서 이미지 방향의 가중치도 \(\hat{\mathbf P}^{\top}\)가 허용한 연결 안에서 따로 학습하려 합니다. 이 구분을 통해 \(\hat{\mathbf P}\)는 해석 가능한 대응 구조를 담당하고, \(\mathbf W\)는 선택된 관계 안에서 실제 activation의 크기를 맞춥니다. 기존 Hungarian 방법은 \(\hat{\mathbf P}\)를 permutation matrix로 제한하고 \(\mathbf W=\hat{\mathbf P}\)로 고정한 특수한 경우입니다.

가중치 \(\mathbf W\)를 별도로 학습하는 이유 permutation matrix는 좌표를 한 번씩 옮기므로 별도의 크기 조정이 필요하지 않습니다. 그러나 여러 연결을 허용하면 한 feature의 activation을 각 연결에 어느 정도 반영할지 정할 필요가 생깁니다. 현재 후보에서는 이 역할을 \(\mathbf W\)에 맡기려 합니다. 주된 비교에서는 모든 대응 구조에 같은 가중치 학습 절차를 적용하고, 선택된 연결에 동일한 가중치를 주는 단순 대조군도 함께 평가하려 합니다. 이를 통해 여러 연결의 효과와 가중치 학습의 효과를 분리할 수 있을 것으로 예상합니다.

부분 \(b\)-매칭을 우선 후보로 두는 이유 이 연구는 어떤 image feature와 어떤 text feature가 연결되는지를 해석할 수 있는 작은 구조를 유지하면서 \(N{:}M\) 대응과 대응 없음을 표현하려 합니다. 부분 \(b\)-매칭은 Hungarian matching의 이진 연결을 유지하면서 이 두 가능성을 추가할 수 있으므로 현재 가설에 비교적 직접 대응할 것으로 예상합니다. 다만 RQ2에서 연속적인 연결 가중치나 전체 latent space의 회전이 더 적합하다는 결과가 나오면 Sinkhorn이나 Procrustes를 주된 방법 후보로 다시 검토해야 합니다.
8

실험이 가설을 지지할 때의 최종 논문 주장

최종 주장은 기존 방법의 한계, 실제 embedding의 구조, 그 구조에서 유도한 방법, 분리된 검증의 순서로 구성합니다.

주장 1. 기존 대응 점수의 한계

coactivation correlation이 높더라도 두 feature가 실제로 같은 의미의 정보를 나타낸다고 단정할 수 없습니다. 의미적으로 공통된 정보가 없는 두 feature도 데이터에서 자주 함께 나타나면 높은 coactivation correlation을 얻을 수 있으며, 이로 인해 Hungarian matching이 서로 다른 개념의 feature를 연결할 수 있습니다.

주장 2. 실제 embedding의 대응 구조

이미지와 텍스트 SAE에서 같은 개념을 예측하는 데 충분한 feature 수와 구성이 다르게 나타납니다. 상대 모달리티의 여러 feature를 사용할 때 시험 표본의 activation reconstruction이 안정적으로 개선되면 작은 feature-set correspondence가 필요하다는 증거로 해석합니다.

주장 3. 실험에서 유도한 방법

모달리티 내부의 중복을 고려한 양방향 ridge regression coefficient로 대응 점수행렬을 만들고, 검증 표본에서 확인한 연결 수와 대응 없음만 허용하는 부분 \(b\)-매칭으로 대응행렬을 구합니다.

주장 4. 해석과 정렬의 공동 개선

대응 점수 개선과 1:1 제약 완화의 효과를 분리해 검증합니다. 최종 방법이 실제로 같은 의미를 나타내는 image feature와 text feature를 더 정확히 연결하는지, 그리고 image-text alignment 성능도 함께 개선하는지 확인합니다.

한 문장으로 정리하면, 이미지와 text SAE feature의 대응이 coactivation correlation과 완전한 1:1 짝짓기만으로 충분히 설명되는지 실제 embedding에서 검증하고, 확인된 한계만 반영한 대응 점수와 작은 부분 대응 구조가 더 정확하고 해석 가능한 cross-modal feature correspondence를 만드는지 보이려 합니다.
이 문서는 완료된 실험 결과를 보고하는 문서가 아니라 후속 연구의 가설, 구조 검증 실험, 예상 결과와 방법 후보를 정리한 제안서입니다. RQ1과 RQ2의 구조 검증을 먼저 수행하고, 그 결과가 가설을 지지할 때 대응 점수와 matching 방법을 별도의 두 번째 단계에서 검증하려 합니다.
